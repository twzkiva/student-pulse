# 🎓 Кампус Пульс (Campus Pulse)

**Кампус Пульс** — це сучасна, швидка та безпечна платформа для студентів, яка об'єднує розклад занять, керування домашніми завданнями та важливу інформацію групи в єдиному преміальному інтерфейсі.

🌐 **Офіційне посилання:** [campus-pulse-ki13.student-pulse.workers.dev](https://campus-pulse-ki13.student-pulse.workers.dev/)

---

## 📱 Як користуватись сайтом (для студентів)

1. **Реєстрація та Вхід:** 
   Сайт підтримує як реєстрацію за email/паролем, так і безпечний вхід через **Google**. Ваші паролі надійно зашифровані.
2. **Розклад та Парність:** 
   Сайт автоматично визначає парність тижня та підсвічує активну пару. Ви також можете перемкнутись на будь-який інший день чи тиждень вручну.
3. **Домашні завдання:**
   Усі завдання синхронізуються через спеціального Telegram-бота. Завдання, які ви додаєте в бота, миттєво з'являються на сайті для всієї групи.
4. **Кастомізація під себе:** 
   Натисніть на ⚙️ **Шестірню** (Налаштування). Тут можна:
   - Вибрати темну/світлу/системну тему та змінити **акцентний колір** кнопок.
   - Увімкнути/вимкнути анімації.
   - **Конструктор блоків:** сховати непотрібні елементи (наприклад, контакти куратора) або змінити порядок блоків (перетягнути домашки на самий верх екрану).
5. **Встановлення як додаток (PWA):**
   Відкрийте сайт у Safari (на iOS) або Chrome (на Android), натисніть "Поділитись/Налаштування" -> **"Додати на головний екран"**. Сайт працюватиме як повноцінний мобільний додаток (навіть без інтернету).

## 🛠 Технологічний стек та Архітектура (Де і як працює)

Проєкт має **Serverless-архітектуру** та безкоштовно хоститься на потужностях Cloudflare.

- **Фронтенд:** Vue 3 (Composition API), Vite, Tailwind CSS. 
  - Дизайн адаптивний, з використанням кастомних CSS-змінних для динамічних тем (Glassmorphism-стиль).
  - PWA (Vite PWA Plugin) з агресивним кешуванням для роботи офлайн.
- **Бекенд:** Cloudflare Workers (`worker/index.js`).
  - Універсальний бекенд, який одночасно віддає файли сайту (Static Assets) та обробляє API запити (`/api/...`).
- **База даних:** Cloudflare D1 (Serverless SQLite).
  - Схеми даних генеруються через Drizzle ORM (`drizzle/...`).
- **Авторизація:** Написана з нуля на базі Cookie (SameSite=Lax, HttpOnly), PBKDF2 (хешування паролів) та Web Crypto API. Підключений Google OAuth 2.0.
- **Синхронізація:** Telegram Webhook API для миттєвого отримання оновлень від бота без потреби постійно його "пінгувати".

## 🚀 Як розгорнути (Deploy) або розробляти локально

Для адміністраторів та розробників. Усе керується через `npm` та `wrangler` (CLI від Cloudflare).

### 1. Локальна розробка
```bash
# Встановлення залежностей
npm install

# Запуск локального середовища
# Відкриє два сервери: Vite (фронтенд) та Wrangler (імітація бекенду бази даних локально)
npm run dev
```
> ⚠️ **Увага:** Для локальної роботи з бекендом потрібен файл `.dev.vars` у корені проекту із секретами (Telegram Token, Google Client Secret тощо).

### 2. Керування базою даних (D1)
Щоб додати нову таблицю або змінити існуючу:
```bash
# Локально:
npx wrangler d1 execute campus-pulse-ki13 --local --file=drizzle/xxx.sql

# На продакшені (реальний сайт):
npx wrangler d1 execute campus-pulse-ki13 --remote --file=drizzle/xxx.sql
```

### 3. Завантаження на Cloudflare (Deploy)
Запуск однієї команди автоматично збере Vue-додаток і відправить код на Cloudflare Worker:
```bash
npm run deploy:cloudflare
```
*Ця команда запускає скрипт `scripts/write-sites-worker.mjs`, який об'єднує зібраний фронтенд із файлом `worker/index.js`.*

## 🛡 Безпека проекту
- **SQL Injection:** Захищено повністю (використовуються `prepared statements`).
- **CSRF / XSS:** Захищено (Vue екранує HTML-код, а Google OAuth перевіряє стан через PKCE `verifier`).
- **БД Паролів:** Ніхто (навіть адмін) не бачить ваших паролів — вони перетворені на хеші з унікальною «сіллю».
- **Telegram Bot:** Endpoint вебхуку приймає запити тільки від серверів Telegram, перевіряючи унікальний криптографічний `X-Telegram-Bot-Api-Secret-Token`.
